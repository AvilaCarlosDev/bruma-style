# Security policy

Hyprglass contains desktop configuration and local helper scripts. It does not
operate a hosted service and it must never include live credentials or private
network profiles.

## Reporting

Use GitHub's private security-advisory flow for vulnerabilities that could
execute unintended commands, expose local secrets or weaken the installer's
backup guarantees. For ordinary bugs, open a public issue.

Do not include working passwords, tokens, private keys, SSIDs or other private
data in a report. Redact paths and screenshots when they identify a machine or
person.

Only the current `main` branch is maintained.
